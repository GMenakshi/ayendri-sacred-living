# Ayendri Sacred Living

Build a premium, visually stunning, fully responsive landing page for **AYENDRI**, a Hindu spiritual products and shopping app. Use https://www.divinehindu.in/ as inspiration for the product category and spiritual aesthetic, but create an original, more modern and luxurious design.

**IMPORTANT: This is ONLY a landing page, NOT an e-commerce website.**

**Branding:** I will provide the official AYENDRI logo. Use it throughout the website without altering it. Follow a sophisticated palette of warm ivory, saffron, orange-red, and subtle gold. Combine Indian cultural elegance with modern luxury branding. Avoid generic templates, excessive gradients, clutter, and tacky religious graphics.

**Hero section:** Create a stunning full-screen hero with beautiful Hindu spiritual product imagery, atmospheric lighting, elegant typography, subtle floating animations, and smooth scroll effects. Include a compelling headline, short description, and prominent buttons: "Download on Google Play" and "Download APK". Use polished micro-interactions and cinematic transitions.

**Dynamic visuals:** Product and lifestyle images must be replaceable easily through a centralized data array or configuration. Use attractive placeholder images for Rudraksha, malas, jewellery, idols, and puja essentials. Never hardcode images throughout components. Add elegant image cards, a horizontal showcase, and subtle hover effects.

**Sections:** Create a premium hero, curated product showcase, "The AYENDRI Experience" brand section, app download CTA, and elegant footer. Keep the content concise and the scrolling experience smooth.

**App downloads:** Add configurable constants for the official Google Play Store URL and direct APK URL. Both buttons must open their respective links. Until I provide the actual URLs, use clearly marked placeholders rather than inventing links.

**Technical requirements:** Use React, TypeScript, Tailwind CSS, and lightweight animation libraries where appropriate. Ensure mobile-first responsiveness, fast loading, optimized images, accessible buttons, and clean reusable components. Add a polished mobile layout and a sticky, minimal navigation bar.

Make the result feel like a premium Indian spiritual lifestyle brand: elegant, immersive, modern, and production-ready. Focus on exceptional visual design and smooth animations rather than unnecessary functionality.
